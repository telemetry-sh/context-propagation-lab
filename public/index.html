THE PREMISE

Context is data. Every boundary is a serialization decision.

A trace ID stored in a convenient ambient variable can look correct in a single request. Under concurrency it may belong to another request. A Dart Zone preserves values across local asynchronous callbacks, but a new isolate has separate memory and receives only what the message carries.

If you graph only HTTP success, every strategy below looks identical.
